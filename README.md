# LaCousine / LatinHub

A colorful interactive food atlas: discover famous dishes by letter, browse culinary regions, meet the people behind the plate, and drag the globe to wander.

## Run locally

No build tools or downloads are required. Open `index.html` in a browser, or use VS Code's Live Server extension for automatic refresh.

## Deploy

This is a static site and can deploy directly through GitHub Pages, Netlify, Vercel, or any static host. Push the folder to GitHub, then enable Pages from the repository settings with the `main` branch as the source.

The site uses Google Fonts and Unsplash image URLs, so an internet connection is needed for the full visual experience. Replace those image URLs with owned or licensed assets before commercial publishing.
